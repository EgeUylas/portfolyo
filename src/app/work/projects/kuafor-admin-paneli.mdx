## Proje Hakkında

Kuaför salonlarının randevu, müşteri ve personel yönetimini kolaylaştırmak amacıyla geliştirilen Süper Admin paneli. Mobil uygulama ile entegre çalışan bu panel, işletme sahiplerinin tüm süreçleri tek bir merkezden yönetmesini sağlar.

## Özellikler

- **Dashboard:** Detaylı istatistikler ve grafikler
- **Randevu Yönetimi:** Takvim üzerinden randevu takibi
- **Kullanıcı Yönetimi:** Müşteri ve personel profilleri
- **Gelir Takibi:** Finansal raporlama ve analizler
- **Karanlık Mod:** Kullanıcı dostu arayüz

## Teknolojiler

- Next.js
- Shadcn UI
- Firebase
- Tailwind CSS
- TypeScript

## Rolüm

Bu projenin web tabanlı yönetim panelini tek başıma geliştirdim. Backend tarafında Firebase kullandım ve verilerin mobil uygulama ile senkronize çalışmasını sağladım.
